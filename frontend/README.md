# BUYC Corp - Frontend Application (Phase I)

This is the frontend user interface for the BUYC Corp second-hand car marketplace. It is a modern, responsive single-page application (SPA) built for car dealers to manage their inventory.

##  Tech Stack
* **Framework:** React.js
* **Build Tool:** Vite (for lightning-fast hot module replacement)
* **Styling:** Tailwind CSS (utility-first CSS framework for rapid UI development)
* **Routing:** React Router DOM (client-side routing)

##  Key Features Included
1. **Authentication UI:** Login and Signup screens for dealers.
2. **Dealer Dashboard:** * Grid view of current marketplace inventory.
   * Dynamic filtering by Max Price, Color, and Min Mileage.
   * Multi-selection and bulk deletion functionality.
3. **Add Listing Form:** A comprehensive form for dealers to add new second-hand car specifications (Images, Title, Price, and 5 key highlights).
